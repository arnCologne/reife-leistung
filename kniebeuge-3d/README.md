# Reife Leistung – Kniebeugen-3D-Prototyp

Eigenständige Prototyp-Seite neben der bisherigen Trainings-App. Die bestehende index.html und README.md im Repository-Hauptverzeichnis werden nicht geändert.

## Aufrufen mit GitHub Pages

Nach einer gesondert freigegebenen Übernahme in den von GitHub Pages verwendeten Branch und Veröffentlichungsordner ist die Seite bei einer Veröffentlichung aus dem Repository-Hauptverzeichnis unter folgender Adresse erreichbar:

https://arnCologne.github.io/reife-leistung/kniebeuge-3d/

Dies ist die vorgesehene URL, keine Bestätigung einer bereits erfolgten Veröffentlichung. Ein separater Feature-Branch wird normalerweise nicht automatisch über die bestehende Pages-Seite bereitgestellt.

## Dateien und Pfade

- index.html: vollständiger Trainingsplaner und Übungsbibliothek; CSS und JavaScript sind direkt enthalten.
- assets/kniebeuge.mp4: echte Blender-3D-Kniebeugenanimation mit einer erwachsenen Sportlerin und einem erwachsenen Sportler; H.264, 768 × 576, 24 fps, 5 Sekunden, ohne Ton.
- assets/kniebeuge-poster.jpg: Vorschaubild vor der Wiedergabe.
- LICENSE-CHARACTERS.txt: ursprünglicher CC0-Lizenztext der Charaktermodelle.

Die beiden Medien werden relativ zur Seite über assets/... geladen. Dadurch funktionieren die Pfade im GitHub-Pages-Unterordner. Es gibt keine externen JavaScript-/CSS-Abhängigkeiten und keine KI-API. Angaben und Pläne werden nur im geöffneten Browser-Tab gehalten. Keine echten Kundendaten enthalten.

## Prototyp-Umfang

Nur die Bibliothekskarte „Kniebeuge“ nutzt das 3D-Video. Die übrigen 17 Übungen behalten ihre schematischen Animationen. Start/Pause, Endlosschleife, Filter und Pausieren im Hintergrund sind vorgesehen. Die Übungsbibliothek wird nicht mitgedruckt.

Das ist ein Look-/Bewegungsprototyp, kein abschließend freigegebenes Technikvideo. Hände, Augen und Kleidungsdetails sind noch vereinfacht; eine fachliche biomechanische Freigabe und ein Test auf einem echten iPad/Safari stehen aus. Technische Boden- und Schleifenprüfungen ersetzen diese Freigabe nicht.
